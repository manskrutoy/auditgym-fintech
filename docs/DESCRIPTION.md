# Описание проекта (для формы сдачи)

**AuditGym** — воспроизводимая RL-среда для дообучения ИИ-аудитора. Это не чат-бот и не отчёт,
а симулятор, на котором модель можно учить и честно оценивать.

Каждый эпизод — вымышленная компания за один отчётный период. Сначала генерируется
согласованная скрытая история: клиенты, счета, платежи, курсы валют. Затем вносятся ошибки, у
каждой из которых записана причина: дубли счетов, нераспределённые платежи, неверная дата
курса и ошибки периода, а также два сценария взаимодействующих ошибок. Есть чистые компании
и корректные «ловушки»: повторяющиеся подписки, разбитые платежи, возвраты, курсы выходных,
документы на границе периода в чужих часовых поясах.

Агент работает через Gymnasium-подобный контракт reset/step и 5 инструментов в пределах 100 шагов,
затем отправляет выводы с доказательствами. Закрытый оценщик сопоставляет их с эталоном один к
одному и выдаёт награду `clip(2·F1 − 1 − 0.002·steps)`. Эталон недоступен агенту: политика
работает в песочнице, а в закрытом режиме награда не возвращается.

Что подтверждено измерениями:
- одна команда `python -m auditgym check`, 78 тестов, включая опубликованные примеры жюри;
- `judge_adapter.py` по определениям проверок жюри;
- 20/20 парных проверок (перестановка, замена ID, смена часовых поясов);
- независимая проверка данных: книги сходятся до ошибок, каждое расхождение доказуемо;
- oracle +1.000, скриптовый эксперт без доступа к эталону +0.969, простая сверка −0.101,
  атака «пометить всё» −1.000; каждый сбой автоматически привязан к ловушке;
- красная команда из 4 независимых агентов проверила утечки, награду, данные и соответствие ТЗ,
  все находки исправлены.

Только стандартная библиотека Python, офлайн, без GPU и платных API. Все данные вымышлены.
